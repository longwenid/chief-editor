## structure（四轴，除此之外不拆）
- genre_promise（题材与读者承诺 → genre 门方向输入）：轻小说·原生幻想 × 蒸汽朋克。承诺："最轻松愉快的奇幻轻小说"（官方宣传语）+穷学生经济压力+吐槽向爽文；读者预期"每章都有小发财/小机锋+美少女关系推进"。
- gimmick_shape（脑洞形状：一条根规则 + 谁与谁博弈 + 兑现节奏 → premise/world 门）：
  - 根规则：主角持有独占的鉴别视角（能看见超凡材料的真实价值——他人眼中的废料/污染物在他眼中是有用资源），把"猎魔"从战斗行为变成低买高卖的捡漏经济行为。
  - 博弈：穷学生（有眼无资本）vs 持有资本与权力的多方（投资他的贵族、雇佣他的帝国、诅咒他的密教）——信息优势兑换生存与阶层的阶梯；学贷是开局债务压力锚。
  - 兑现节奏：单元捡漏（每个发财机会一次兑现）+关系网扩张（贵族/猎人/帝国/密教逐方入场）+阶梯尽头挂终极目标（神话级源质=飞升成神，按简介推断）。
- rhythm_volume（章幅/卷结构/字数/在读或月票 → scale 门档位参考）：110.35万字 / 330章 ≈ 3344字每章；书友数 65.52万；2026-10 月票 3.12万票列第 18；"万订上新"徽章+宣传语称均订2万——轻小说频道付费中上体量档（对照快照：月票榜轻小说 3 席之一）。
- payoff_shape（兑现方式 → payoff 门参考）：早期兑现物明确（学贷压力→首单捡漏闭环）；阶段回报=每方势力入场带来一次阶层跃迁；终局回应预挂（"全世之真理"级目标）——三层兑现结构在简介中完整可见。
